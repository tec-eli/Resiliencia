# Security Policy

## Supported Versions

resiliencia is in early development (pre-1.0). Security fixes are applied only to the latest code on `main`; there
are no maintained release branches yet.

| Version | Supported |
| ------- | --------- |
| main    | ✅ |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately through [GitHub Security Advisories](https://github.com/tec-eli/Resiliencia/security/advisories/new)
for this repository. This creates a private discussion with the maintainers before any details become public.

Include as much detail as possible:
- Affected module(s) and version/commit
- Steps to reproduce or a minimal proof of concept
- Potential impact

You should expect an initial response within 7 days. If the report is confirmed, we will work with you on a fix and
coordinate disclosure timing before any public advisory is published.
